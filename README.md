Fabulor — from Latin fabulor, “to chat, talk, converse.”\
A modernised GTK4 IRC client for Windows 11+, inspired by [XChat](https://xchat.org/), [HexChat](https://hexchat.github.io/), and [ZoiteChat](https://zoitechat.org/): fast, simple, and highly scriptable with C#, Python, and Tcl.
