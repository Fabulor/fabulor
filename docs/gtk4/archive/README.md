# GTK4 Historical Evidence

This directory preserves completed GTK4 migration and installed-acceptance
records. They document decisions, intermediate states, test results, and manual
acceptance evidence from the conversion.

These files are historical evidence rather than current implementation
instructions:

- [Migration plan](migration-plan.md)
- [API inventory](api-inventory.md)
- [Validation log](validation-log.md)
- [Installed UI acceptance handoff](GTK4-Installed-UI-Acceptance-Handoff.md)

Current GTK4 architecture, runtime packaging, and maintainer guidance remain in
the parent `docs/gtk4` directory. Archived records should change only for link
repair, factual correction, or an explicit archive-policy update.
