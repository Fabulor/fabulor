# FiSHLiM in Fabulor

Fabulor maintains this bundled FiSHLiM fork. Its lineage is the original
XChat/HexChat plugin followed by the ZoiteChat client fork; there is no current
standalone FiSHLiM upstream.

The bundled plugin uses Fabulor's current native plugin ABI. Historical
attribution remains with the original projects; ongoing maintenance belongs to
Fabulor.
