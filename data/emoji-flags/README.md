# Emoji Flag Assets

The PNG flag assets in this directory were downloaded from Flagpedia's icon
collection on 2026-07-14:

https://flagpedia.net/download/icons

Flagpedia states that its downloadable flag images are in the public domain
and may be used freely in commercial and non-commercial software:

https://flagpedia.net/terms

The set contains 253 two-letter region assets used by Fabulor's flag picker
and four UK subdivision assets (`gb-eng`, `gb-nir`, `gb-sct`, and `gb-wls`).
The picker does not list `CP`, `DG`, `EA`, `IC`, or `TA` because this icon set
does not provide those entries. `EU` is retained.
