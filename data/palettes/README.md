# Bundled palettes

`Fabulor Dark.hct` is an original Fabulor colour palette. Its source is
`Fabulor Dark/colors.conf`; the archive intentionally contains no event
configuration or executable content.

The palette is distributed under the same GNU General Public License,
version 2 or later, as Fabulor. It is installed as a read-only bundled
palette. User palettes remain separate under the profile `themes` directory
and take precedence over a bundled palette with the same name.
